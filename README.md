# Python Spell Checker

This is a simple **Spell Checker project built in Python** while learning Python programming.

The program takes text input from the user and corrects spelling mistakes using the **pyspellchecker** library.

## About This Project

I created this project **while learning Python** to practice:

* Python classes
* Loops
* Functions
* Working with external libraries

This is a beginner-friendly project and part of my learning journey.

---

## Why I Used a Virtual Environment

I created a **virtual environment** to keep the project dependencies separate from the global Python installation.

Using a virtual environment helps to:

* Avoid conflicts between different project libraries
* Keep the project dependencies isolated
* Make the project easier to manage and reproduce on other systems

---

## Installation

### Create a virtual environment

```bash
python -m venv venv
```

### Activate the virtual environment

Windows

```bash
venv\Scripts\activate
```

Mac / Linux

```bash
source venv/bin/activate
```

### Install required library

```bash
pip install pyspellchecker
```

---

## Run the Program

```bash
python main.py
```

---

## Example

```
Enter text to check: helo wrld
Correcting "helo" to "hello"
Correcting "wrld" to "world"

Corrected text: hello world
```
